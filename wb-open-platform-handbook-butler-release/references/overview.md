# 平台概述与资产选型

> 来源：官方文档 /docs/what-is-open-platform、/docs/contact ｜ 同步日期：2026-10-24

WorkBuddy 是腾讯的 AI Agent 办公客户端（PC 本地助理 + 云端任务 + 多 Agent 协作）。开放平台（open.workbuddy.cn）让开发者把行业 know-how 做成标准化资产上架市场。官方自我定位：桌面办公智能体第一，10万+ 生态资产，100+ 家共创伙伴。

## 开发者全流程

注册入驻 → 资质认证 → 创建资产 → 完善配置 → 测试环境调试验证 → 提交平台审核 → 审核通过发布上线 → 看运营数据持续迭代（每次更新需重新提审）。

## 六类资产对比与选型建议

| 资产 | 形态 | 适合 | 能否收费 |
| --- | --- | --- | --- |
| 技能 Skill | SKILL.md + references/scripts/templates 的 zip | 可复用任务指令、工作流、知识库 | ✅ 买断/按月 |
| 专家 | plugin.json + agents/*.md 人设提示词 + 头像 | 单角色 AI 顾问，人设化服务 | ✅ 买断/按月 |
| 专家团 | expertType=team，主理人+多成员协作 | 多角色 SOP 流程，演示性强 | ✅ 买断/按月 |
| 连接器 | MCP+Skill（推荐）或 CLI+Skill | 接第三方服务/自有 API | ❌ 暂免费 |
| Buddy 应用 | 平台表单配置的行业 AI Harness | 垂直行业工作台（需企业主体） | 企业单 B2B 授权 |
| 第三方应用 | OAuth 2.1 + Open API / 分享 SDK | 硬件接入、积分兑换、分享回跳 | 权益类 |

**选型建议**：纯知识问答/指南类 → 技能；需要人设与信任感 → 专家；流程复杂多环节 → 专家团；要调外部系统 → 连接器；面向机构整体交付 → Buddy 应用（需企业主体）。

**主体与能力**：个人主体可发布技能/专家/连接器并开通收入变现；Buddy 应用、企业单、分享接入需企业主体（个体工商户按企业认证对待）。

**联系官方**：openworkbuddy@tencent.com；开放平台首页下方有官方社群二维码。
