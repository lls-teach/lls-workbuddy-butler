# 入驻与实名认证

> 来源：官方文档 /docs/onboarding ｜ 同步日期：2026-10-24

## 三种认证主体

| 主体 | 适用 | 要点 |
| --- | --- | --- |
| 个人认证 | 个人开发者 | 二代身份证+实名手机号+邮箱+人脸识别；一个身份证全平台只能认证一个个人主体；每账号最多 1 个个人主体 |
| 企业认证 | 持营业执照主体：公司、合伙企业、个人独资企业、**个体工商户** | 三种方式：企业法人实名认证（法人扫码人脸+四要素）/ 腾讯云账号快速认证 / 微信公众号·小程序快速认证；每账号最多认证 10 个企业主体，同一企业最多被 50 个账号认证 |
| 其他组织机构认证 | 无营业执照的组织（事业单位、社团、律所等） | 腾讯云或微信授权认证；同一信用代码只能认证一个主体 |

- 企业认证需上传营业执照，OCR 识别后核对名称、统一社会信用代码、法定代表人；填写对外展示的开发者昵称并通过命名校验。
- 不支持海外主体；仅支持中国大陆二代身份证。
- 认证只采集实名信息；对外展示的头像/昵称/简介在「设置 → 开发者信息」填写（规范见 operations-profile.md）。

## 常见认证失败与处理

| 场景 | 处理 |
| --- | --- |
| 三要素不一致 | 核对姓名/身份证/手机号同一人；超限后稍后重试 |
| 手机号未实名 | 用本人已实名且与身份证一致的手机号 |
| 人脸比对不通过 | 本人操作、光线充足；连续 5 次不一致锁定 5 分钟 |
| 身份证已被占用 | 一个身份证只能有一个个人主体，用原账号 |
| 授权失败 | 先在腾讯云/微信完成该主体实名认证再发起 |
| 第三方主体不一致 | 确保用同一组织的腾讯云/微信账号授权 |
| 海外主体 | 暂不支持 |
