# 服务类目与资质（要点版）

> 来源：官方文档 /docs/service-categories-individual、/docs/service-categories-enterprise（完整类目表以官方页面为准，此为高频要点）｜同步日期：2026-10-24

## 什么时候需要选服务类目

纯**技能 / 专家 / 连接器**上架不涉及服务类目；做**第三方应用、Buddy 应用**等业务型产品时需按主体类型选择类目并提交资质。个人主体可选类目极少，企业主体（含个体工商户）类目齐全。

## 个人主体（类目少，多数无资质要求）

物流查件、装卸搬运、教育信息展示（**仅展示，明确不支持卖课/视频直播**）、代驾、丽人（美甲美发等）、婚庆、家政、餐厅排队、出境WiFi、工具类（记账/日历/天气/办公/图片处理/计算器/信息查询/预约报名/健康管理/备忘录）、企业管理工具、会展、公关推广市调、摄影扩印、体育培训、在线健身；商业服务中"律师"需《律师执业资格证》。

## 企业主体高频类目（教育方向重点）

| 类目 | 资质要求 |
| --- | --- |
| 课程销售 | ICP 备案/许可证 + 执照含"教育咨询服务" + 盖章的交易纠纷处理机制 |
| 在线视频课程（网课/直播） | 5 选 1：民办学校办学许可证 / 非学科类校外培训机构培训许可证 / 文化艺术类审核意见书 / 全国校外教育培训监管平台备案 / 教育部门批准文件 / 信息网络传播视听节目许可证 |
| 成人技能培训 | 3 选 1：办学许可证 / 人社部门职业培训备案许可 / 事业单位证书（范围含教育） |
| 课程销售平台（多机构） | 增值电信业务经营许可证（在线数据处理与交易处理） |
| 学历教育（培训机构/学校） | 办学许可证等 |
| 教育平台 | 增值电信许可 + 2 家以上机构合作 + 机构办学许可 |
| 教育装备 | 无资质要求 |

其他常见：IT 科技多数方向资质要求低（软件/网站等一般无前置）；直播需《信息网络传播视听节目许可证》或全国网络视听平台备案；深度合成（AI 生成内容）有专门类目与备案要求；金融、医疗、政务类目资质门槛高。

## 实务建议（社区经验）

- 卖"知识资产"（技能/专家）不触发类目资质，远轻于卖"课程"（应用形态）；
- 执照经营范围建议含"教育咨询服务、信息技术咨询服务、软件开发"留口子；
- 涉及在线视频课程再按官方页面核对当期要求，类目表会更新；
- 每个类目的政策法规依据（许可证对应法条原文与示例）见官方 /docs/legal-basis-and-examples。
