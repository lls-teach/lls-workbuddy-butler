# Buddy 应用（垂直行业 AI Harness）

> 来源：官方文档 /docs/buddy-app ｜ 同步日期：2026-10-24

定位："伙伴不造产品，造配置"。把行业 know-how 装进 WorkBuddy 的 AI 底座，用户打开即得行业专属工作台。需**企业主体**（个体工商户可）。

## 六大自定义维度

1. **工作模式**：System Prompt + 绑定 Skill，模式级 Harness（建议 2–4 个，过多增加选择成本）
2. **场景胶囊**：输入框上方快捷提示词模板，可绑定专家/Skill/案例（如"生成晨报""备课助手"）
3. **模型配置**：从平台模型池勾选（HY、GLM 等）、排序、指定默认模型
4. **垂直行业市场**：自建或引用生态中的 Skill/专家/连接器/灵感案例
5. **内嵌已有功能**：MCP Apps 接入已有系统，不推倒重来
6. 底座能力由平台提供：多 Agent 协同、上下文压缩、记忆工程、工具编排、安全管控

## 配置与发布流程

创建应用（生成 Client ID/Secret，**Secret 仅展示一次**）→ 创建审核通过进入草稿 → 5 个模块配置（创建/首页/市场/其他/预览调试，可跳步，**每次退出前导出配置 JSON**）→ 预览调试（下载对应版本客户端打开预览态）→ 提交配置审核 → 发布上线。已发布应用变更需重新提审。

设计规范：应用 icon 16×16、线宽 1.2px、有断口、圆角 100%；专家页精选场景背景图 1000×910，底图+3 层渐变蒙层，日夜间各一套，极简插画风格（官方提供规范包下载）。

## 企业单管理（B2B 授权）

把已发布 Buddy 应用授权给购买企业版 WorkBuddy 的企业（分发范围勾选"发布到企业"）。流程：新建企业单（需企业 ID+名称、联系人、授权模式全员制/席位制、时长 3 个月/半年/1 年）→ 复制授权链接发给企业管理员 → 管理员在 www.workbuddy.cn/admin 确认 → 应用自动出现在该企业管理后台。链接长期有效但一次性；**同一应用对同一企业暂只能开一次企业单**；可提前终止（管理员确认后生效）；到期自动终止并移除。

## 最佳实践（官方建议）

先梳理目标用户至少 5 个高频场景再组织能力；先发最小可用版本再迭代；通过 MCP Apps 复用已有系统降低迁移成本。
