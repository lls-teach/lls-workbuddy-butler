## 事故教训（仍然有效）

Windows 上做超长路径测试时，**测试工具自身的 cwd 一旦进入超 260 字符路径，进程将无法启动**（上一会话因此 shell 全灭）。正确姿势：外层 shell 永远留短路径，进深路径一律用子进程 `cmd /c "cd /d <深路径> && <命令>"`，操作文件用绝对路径。本轮用「Python 探针脚本 + 字符串命令行」复现并量化了该限制（`WinError 267`），深路径测完即删。

## 一个工具坑（本轮踩到，记录以免重犯）

`subprocess.run([...])` 以**列表**传参时，Python 会用 `list2cmdline` 给内层引号加反斜杠转义（`\"`），而 cmd.exe 不认这种转义，会把合法路径判成「文件名、目录名或卷标语法不正确」。测 cmd 行为时要传**完整命令行字符串**：`subprocess.run('cmd /c "cd /d "…" && …"')`。
