# 数据看板入门课

## 一、课程定位
- 面向对象
  - 有 Excel 基础的运营岗
  - 需要周报的数字营销岗
- 学习目标
  - 能独立做出单页看板
  - 能说清每个指标的口径

## 二、核心内容
- 指标口径
  - 日期粒度与口径对齐
  - 单位与汇总方式
  - 指标定义要写进页面
- 数据准备
  - 每日快照落盘
  - 缺失值的处理约定
  - 快照文件的命名规范
- 图表选择
  - 趋势用折线
  - 对比用柱状
  - 占比用饼图但不超过四类

## 三、作业与考核
- 平时作业
  - 一周快照收集
  - 单页看板交付
- 结课考核
  - 看板讲解五分钟
  - 口径答辩

## 四、常见误区
- 用演示数据交付
- 不标数据截止时间
- 图表堆砌没有结论
