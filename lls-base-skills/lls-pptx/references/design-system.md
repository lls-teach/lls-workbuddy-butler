# 设计系统（lls-pptx v2.4）

> 本文件是 lls-pptx 的视觉决策知识库，自研整理。生成 PPT 前先按第一节做风格简报，再按第五节选风格配方。完整配方原文见 references/（foundations、6 份配方、简报模板、Node 路线实现指引）；本节是 token 与轮廓的执行摘要。

## 一、风格简报模板（生成前的必做动作）

先用短语回答，再动手设计：

**沟通**：受众／期望结果／场合与观看距离／内容类型／可编辑需求。

**论题**：三个形容词 + 一个有益张力（"___但___"）+ 主风格 + 辅助影响 + 绝不能像什么。
例："分析性、紧凑、冷静——张力在于数据密集但有人味儿"。

**系统**：背景行为／母题来源／图案位置与强度／文字层级／强调逻辑／图片行为／形状与线条语言／密度／垂直节奏／页脚与来源行为。

**版式词汇**：三个常驻轮廓 + 一个刻意对比页 + 封面行为 + 收尾行为。

**remix 开关**：列出四个可调维度（饱和度、对称、图片比例、边框强度、字体对比、信息密度等），调它们不变身份。

**QA 五问**：必须含标题与内容间距、底部是否收住、可读性、风格连续性、装饰是否服务沟通任务。

写不出论题就先问用户三个问题：给谁看（受众）／要促成什么判断（目的）／在什么场合投出来（场景）。答案决定密度、配色与版式。

**密度按阅读行为选**：

| 密度 | 适用场景 | 手段 |
| --- | --- | --- |
| 低 | 发布会、故事、煽动 | 大字、少字、满版图 |
| 中 | 内部同步、培训、路演 | 标准要点页 |
| 高 | 决策会、研报、述职 | 分组证据 + 对齐列 + 明确结论，**不是缩小字号** |

## 二、四层级、三层间距与灰度检验

**四层级**：论点、章节标签、证据、注释。一页在灰度下、缩略图尺寸下仍能读出层级，颜色和母题只起强化作用，不替代层级。

**三层间距**：

- 宏观：页边距、标题间距、内容场、页脚。
- 中观：面板之间、列之间、图表与表格组之间。
- 微观：行高、标签与数值的距离、要点间距、文本框内边距。

相关项靠近、无关项 visibly 分开。行高松而字显小时，先减行高，把省出的空间还给更大的字或更强的注释。

## 三、垂直节奏（16:9 页带模型）

一页分六条带，用比例不用坐标：

| 带 | 位置（页高） | 内容 |
| --- | --- | --- |
| 页眉带 | 0–6% | 章节标签 / 页码 / LOGO |
| 论点带 | 6–14% | 页标题，一行以内 |
| 分隔带 | 14–18% | 留白，给眼睛一个停顿 |
| 证据场 | 18–90% | 主表格 / 图表 / 要点 / 对比 |
| 结论带 | 88–93% | 本页结论或来源（可选） |
| 页脚安全区 | 93–100% | 页码，保持视觉独立 |

参考节奏：标题在页高 10–13% 处结束，证据场从 15–18% 开始，有用内容延续到 88–92%。最常见的失败：标题贴着第一行内容、底部整条空白。修法是拉开标题与内容的间距、把证据场向下延展。

## 四、角色化配色（不背色值，背角色）

每套风格只定义六个角色：背景／主文字／次文字／强调／语义（绿黄红）／细线。禁止超出角色的颜色；强调色一页最多用两处。双证据色风格（如咨询的藏青 + 青）算一对，不算两种强调。

## 五、七套内置风格（--style 参数）

### formal 正式工作汇报（缺省）

- 论题：严谨、有序、克制。让状态、偏差、决策在会议上一眼可扫。
- 配色：暖白底 FAFAF7、近黑主文字、藏蓝强调 1F469C、语义色只用于状态。
- 版式轮廓：执行摘要 + 进度行 + 偏差表 + 决策行；状态行 + 实际 vs 目标 + 偏差说明；交付表 + 证据完整度 + 阶段结论；KPI 总览 + 对比图 + 驱动分析 + 行动；风险表 + 分布 + 治理节奏；决策表 + 建议 + 决策后状态；四周计划 + 治理节奏 + 执行要求。
- remix：更资深（减装饰、只留关键决策）／更执行（加负责人、日期、依赖、状态标记）／更财务（强化表格对齐与偏差逻辑）／更机构（克制封面母题 + 正式元数据）。
- 失败信号：标题过大压住内容、行高松而字小、圆角卡片堆成仪表盘感、状态色变成装饰、正文紧贴标题、底部三分之一空着。

### consulting 咨询研报

- 论题：分析性、压缩、冷静。每页一个论点，证据承重；结论在前，证据在后，启示始终可见。
- 配色：冷灰底 F2F4F7、白面板、近黑主文字、藏青 1F4E79 + 青 0E7C7B 证据色、细灰线；来源与方法学注释可见但从属。
- 版式轮廓：论点行（完整句）+ 证据网格（两列对比／数据小倍数）+ 来源行；叙事要点 + 图表 + 统计 + 行动；双图表 + 关键统计 + 能力矩阵；市场图 + 对比图表 + 启示；瀑布 + 驱动 + 假设 + 敏感性；情景列 + 跨情景对比表；建议表 + 验证阈值 + 实施节奏。
- remix：更企业（减青、重藏青与灰）／更现代（标题更大、边框更少、一个鲜明证据色）／更学术（方法学注释加重、色彩中性化）／更执行（解释文字缩短、决策／负责人／阈值加强）。
- 失败信号：话题式标题、标题贴着第一块面板、每个模块等权、图表旁边没有解读、来源不可读、只靠小字号堆密度、证据与结论分离在两页。

### teaching 教学课件

- 论题：清晰、亲和、节奏感。一页一个知识点，视觉锚点帮助记忆。
- 配色：浅色底、深主文字、暖色强调（橙／青双强调允许）、大号正文。
- 版式轮廓：知识点页（要点 ≤4 条 + 图示位）+ 练习页（问题大字 + 留白）+ 章节分隔页（满版色块）；学习进程：问题 → 背景 → 证据 → 因果 → 综合 → 讨论；年表带（转折点 + 短说明）、因果链（证据 + 后果）、文物／图片细读（两三个注释）。
- remix：更低龄（字更大、图更多）／更学术（证据链更完整、来源更显眼）。
- 历史题材：请用 `history` 风格（见下），不要在 teaching 里拼历史变体。
- 失败信号：一页塞进课本整节、字号低于 18pt、连续 5 页同版式无变化、中央阅读区被图案压住。

### history 历史教学

- 论题：学术、叙事、有时代感；是当代人对史料的解读，不是古装剧海报，也不是做旧仿古。
- 沟通任务：帮学习者连起年代、制度、地理、原因、后果；学习进程：问题 → 背景 → 证据 → 因果解释 → 综合 → 讨论。
- 配色：暖纸底、墨色、矿物蓝绿主导、克制朱砂、哑金点缀；朱砂只用于日期、转折点、有争议的主张。
- 字体层级：宋体主导（标题／论点／大日期／综合句用宋体，正文与标签用中性黑体，楷体只用于极少量短引文与图注，不用于长正文与密表）；字号参考：封面 44–60、论点 30–36、副标题 18–24、正文 14–18、来源 10–12，按场合调，不全局缩小；字体取目标环境已有的（Windows 用宋体 + 微软雅黑）。
- 背景母题系统：母题取自主题本身（地图水系、城墙街巷、屋顶格栅、印章、纸纹、等高线、 verified 器物简化形）；封面用一幅沉浸背景或大裁剪 + 安静标题区；分隔页加深或反色、放大同一母题；内容页图案只放角、边、页脚或淡结构场，中央阅读区干净；地图／时间线页让路线、等高线、网格逻辑本身成为构图基底；收尾页低对比复现封面母题。
- 版式轮廓：年表带（转折点 + 短说明）；简化地图／路线图（可编辑标签）；制度对比（对齐列或层级图）；因果链（证据 + 后果）；文物／图片细读（两三个注释）；课堂综合页（可辩论的问题 + 证据提示）。
- 图片行为：地图、建筑、景观、器物、历史地插画优先；生成氛围背景时注明"历史灵感、无文字、无水印、无虚构铭文、无声称真实文物"；说明标签保持可编辑。
- remix：更课堂（年表与问题更突出）／更学术（来源与考据注释更重）／更叙事（地图与路线比重更大）。
- 失败信号：图案来自通用文化俗套而非主题；中央阅读区不够安静；年代、原因、证据、解读分不清；底部靠装饰收住；历史主张与视觉来源不可追溯；**把生成的图说成真实文物来源**。

### civic 社区党建

- 论题：庄重、扎实、有当代感。表达集体参与与中国文化特征，但不要每页都做成节日海报。
- 配色：深红、暖米、哑金、深墨，成套使用不铺满；对称 + 圆形／放射母题，暗示聚合与延续。
- 版式轮廓：居中封面 + 安静社区背景；主题陈述 + 情境图 + 参与结构；活动议程 + 角色 + 场地时间；社区地图／服务站 + 行动清单；三阶段参与流程 + 责任；成果故事 + 下一步行动。
- remix：更政府（对称加强、插画减少、红带与元数据加强）／更社区（暖照片 + 人的故事）／更文化（纸、印、格栅、山水点到为止）／更年轻（红色更亮、形状更简）。
- 失败信号：每个模块都是圆形、红金铺满整页、封面标题过大或偏轴、装饰符号压过活动信息、中国味只剩节日俗套、照片像贴上去的。

### art 艺术市集

- 论题：鲜活、好玩、有策展感。第一眼像创意市集海报系统，细看有秩序。
- 配色：少量高饱和色 + 一个接地深色或中性色；留白本身当形状用，不要填满每个空。
- 版式轮廓：海报封面（超大标题 + 一主视觉）；摊主／艺术家 lineup 排版场；日程表（色彩时间带）；作品拼贴 + 简短图注；地图／导览（粗地标）；收尾海报（行动号召 + 活动信息）。
- remix：更时尚（裁剪更利、黑点缀、编辑字体）／更手作（暖纸质感、手工痕迹、不规则边）／更流行（原色更多、几何形更多）／更地下（深底、荧光点缀、压缩排版）。
- 失败信号：每个元素都抢注意力、饱和无层级、重叠伤可读、海报语言硬套 dense 运营表、贴纸感随机、整套失去连续性。

### editorial 编辑画册

- 论题：安静、有文化、有空间感。让图片、字体、序列本身营造展览感。
- 配色：中性或淡彩底、深墨、克制单强调；细线、小页码、克制字体，不用装饰容器。
- 版式轮廓：极简封面（一作品 + 小元数据）；满版图 + 窄图注栏；双联／三联（共享基线）；策展陈述 + 引言 + 细节图；时间线／来源页（编辑线）；收尾索引／展览注记。
- remix：更博物馆（中性、来源、克制间距）／更杂志（字体对比、裁剪力度）／更实验（非常规比例、旋转、序列，保可读）／更商业（行动号召、服务、藏品信息更明确）。
- 失败信号：留白没有构图目的、裁剪不一致、图注漂浮不对齐、每页重复同一图文布局、装饰框压过作品、整套像网页画廊不像演示序列。

## 六、证据组合

图表看模式，表格做精确对比，文字做解读，图片给语境或情绪。解读贴着证据放，不要把结论和证据分在两页。面板只在澄清分组时用；满屏等高卡片会让一页像软件界面。原生文字、表格、图表、简单形状优先于扁平图，方便复用；性格靠比例、字体、线条、裁剪、节奏来，不只靠贴图。

## 七、背景身份层

背景图案、质感、装饰是低频身份层，不是填空。母题取自主题本身：地理、物质文化、建筑、工艺、符号、抽象结构。按页面角色用：

- 封面锚点：可识别的场、裁剪或母题，承载整套身份。
- 章节过渡：加深或反色，放大同一母题，改变节奏。
- 边缘装饰：角、边、页脚母题，阅读场保持安静。
- 场地质感：淡纸纹、颗粒、等高线、重复纹，防止表面发 sterile。
- 图解基底：地图网格、路线轨迹、轴线、建筑几何，帮着组织内容。

背景强度是叙事信号：封面、分隔页、刻意对比页最强，证据重的页最安静。标题、证据、图注、来源永远是背景之上的可编辑层。图案不要出现在 dense 文字、表格、图表标签背后；优先裁剪与局部重复，不要整面平铺同一母题。

## 八、图片行为

- 图片只放进证据场；图注保持可编辑文字，不要烧进图里。
- contain：等比居中，不变形，适合图表与证据图。
- cover：先按目标框比例裁好再放（像素级裁剪，不是运行时裁剪），避免渲染器对裁剪比例解释不一致导致走样；150–220 像素／英寸一般够用，细图可更高；保留原图以备改版。
- 大纲写法：`[IMAGE] 图片路径|说明|contain`（cover 同理）；图片页建议独占证据场，不要同页再叠表格。

## 九、单行 token 保护

页码、KPI 数字、百分比、金额、日期、季度、周次、大写代码这类短值，在窄盒里容易被自动换行堆成竖条。识别规则：≤16 字、无双空格、无换行，且符合纯数字／百分比／金额／日期／季度／周次／大写代码任一形态。

保护做法：不换行、零边距、缩小兜底；先估算宽度（拉丁／数字按 0.62em，全角字符按 1.0em，+0.14in 边距，×1.15 安全系数），盒子比估算窄就先缩字号到下限，仍窄就告警。给 token 一个合理的盒子宽度，不要靠缩小兜底来掩盖盒子过窄。语义已知的 token（页码、KPI 数字）直接走保护，不必先过识别。

## 十、要点页规则

- 一页要点 ≤6 条，超出主动拆页或转两列证据网格。
- 每条要点 ≤2 行；需要长句就改成"短句加粗 + 冒号 + 说明"。
- 序号、日期、百分比、金额保持数字原生，不要转图片。

## 十一、视觉问题诊断（自查九问）

- 标题是结论还是只起了个话题名？
- 标题与证据之间有没有明确的停顿？
- 视觉重心是不是太高、太低、太左、太右？
- 底部是不是有意收住的？
- 行高相对字号是不是太松？
- 最小的有效文字在目标场合能不能读？
- 颜色是不是按语义角色一致使用？
- 每个装饰是不是都服务身份、层级或导航？
- 相邻两页的轮廓是不是太像？

## 十二、验证纪律（省时省渲染）

1. 生成后只做一次全量渲染。
2. 程序化检查（pptx_check.py）先跑：空占位符、超密度页、要点超量、单行 token 溢出、图片拉伸。
3. 先看缩略图总览，再细看：封面、信息最密的一页、图表页、结束页、总览中的异常页。
4. 只改受影响页，不重复渲染没变的部分。
5. 交叉渲染（PowerPoint / LibreOffice / Google Slides）只在用户明确要求跨应用交付，或字体、裁剪、图表、媒体存在已知风险时做。
6. 没有新的视觉变化就不重复验证。

## 十三、实现结构（四层与快速构建循环）

不论 Python 还是 Node 路线，同一套结构：

1. **内容模型**：论点、证据、数据、来源、页面角色。
2. **设计 token**：角色配色、字体角色、间距节奏、线条、语义色。
3. **基础构件**：文字、规则线、面板、图片、图表、表格、进度、来源、页码；页眉、来源行、页码这类重复 chrome 只写一次。
4. **页面组合**：按叙事任务命名的布局函数；风格变体用配置对象，不复制整套生成器；不要把全部样式和坐标塞进内容代码。

颜色按角色表达（墨色、次文字、强调、表面、肯定、警示、风险），字体按角色表达（封面标题、论点、章节标签、正文、注释、来源），间距用小刻度加统一外边距，组合特例除外。短值（序号、日期、百分比、金额、页码、周次、代码）走专用单行构件，不当普通段落。原生文字、表格、图表、简单形状优先于扁平图；图片是内容时才用光栅图，图注与注释保持可编辑。

**快速构建循环**：起草叙事与简报 → 定 token 与组合 → 整套直接生成 → 结构检查 + 一次渲染 → 缩略图总览（看层级、节奏、重复、底部收束）→ 封面、最密页、特殊媒体或图表页、结束页、总览异常页全尺寸细看 → 只改受影响页。

**选择性升级验证**：新视觉系统、长套重复版式、组合 fit 不确定时，先渲两三页代表页；高风险、异常 dense、 workflow 明确要求时，逐页全尺寸；交叉渲染只在明确要求或字体、裁剪、图表、媒体、SVG、导入母版有已知风险时做；同一裁剪 A/B 在 helper 已验证且管线未变时不重做。

**弱设计症状**：全局缩小字号解一切溢出；重复 addText 导致间距漂移；图表脱离面板与注释独立移动；标题与正文坐标假设不一（标题贴面板、底部空带）；同一卡片网格套所有页；风格变体复制整套生成器。先在设计系统层修，不要逐页打补丁。
