# 审美门禁：反套路框架的幻灯片版

来源：taste-skill v2（Leonxlnx/taste-skill，MIT 协议，The Anti-Slop Frontend Framework for AI Agents），
由 247 个获奖站点研究提炼。此处为幻灯片改写版，只取其判断与纪律，不照搬网页做法；
原文见该仓库 `skills/taste-skill/SKILL.md`。做 PPT 前先读本文件，再读风格配方。

## 0. 诊断：模型默认出片长什么样

居中标题、标题上方一个小标签、三张图标卡、柔和渐变、细线、等宽小字。
没有一处是错的，也没有一处是经过决定的。本节的任务就是把每个默认换成一个决定。

## 1. 主张先行，再谈样式

1. **主题清单**：写 8–12 条只属于这个主题、竞品没有的东西——名字与含义、地点与街道、
   数字、约束、材料与颜色、仪式与时间、它那个世界的印刷品（时刻表、标签、票据、招牌）。
   这张清单是 idea 的来源，也是找图的查询词。
2. **论点**：每页先写一个主张加证据，一页一行；没有主张的页删掉。不要先套 hero、三特点、
   客户证言、定价、行动号召这种固定顺序。
3. **idea 句**：在动笔前写出这句话，两个空都必须来自主题本身：
   > 在这份 deck 里，[主题独有的东西] 变成 [版式装置]。
4. **竞争者测试**：把最近的竞品代入这句话，还成立就是品类句，重写。
   "干净现代"不是 idea；"面包"是所有面包房的，"这条街七扇门"才是这一家的。

## 2. 选型：六套风格就是方向库

- 按主题契合度选一个，并写一句话理由；不舒服的优先选，熟悉的版式正是本节要防的东西。
- 不混搭。本文件取代"有意识地组合两种风格"的做法：主风格之外不平均第二种风格。
- 只在三种情况下换局部，且须说出理由：与品牌约束冲突、素材不存在、版式装不下真实内容。
- 调色按比例拿（底、墨、强调、色块各占多少），颜色可以换成主题自己的材料色，
  比例不变；主题色与调色打架时，先换一次调色，主题色极明确时保留比例换颜色，并写进报告。

## 3. 门禁清单（生成前逐项过）

- **标题不超过两行**【数据】：删词 → 放宽幅面 → 最后才缩小字号。
- **封面有且仅有一个主标题；每页都有标题**【品味】，标题说清这页是什么。
- **无眉标**【数据】：标题上方的小标签、药丸徽章一律去掉，信息放进标题或首句。
- **无编号标签**【品味】：01/02、(001)、Step 2 一律不用；顺序由位置、字号或文字本身表达。
  页码 folio 不算编号标签。
- **无细线分隔**【品味】：不用 1px 线、网格线、裁剪标记分隔；用留白、底色台阶、字号变化分隔。
- **无渐变**【数据】：背景、按钮、文字都不用；照片下压字的中性罩网是唯一例外。
- **无静止阴影、无辉光**【数据】：表面之间用底色台阶区分；阴影只给真正浮起的东西（菜单、对话框）。
- **无助手配色**【数据】：黄奶油底加陶土/锈红、紫/靛一律不用。品牌或题材自带色例外但须注明
  （党建红金是题材色，不是助手色）。
- **无小号全大写字母间距标签**【数据】：用正常语序、可读字号；正文用全墨色，灰色只给次要注脚。
- **无图标卡片阵、无成排相同卡片**【数据】：按蓝图做版式，不用卡片网格凑数。
- **无玻璃拟态、无 emoji、无渐变色块、无装饰形、无灰条假仪表盘**【数据】。
- **标题不做花式强调词**【品味】：斜体、变色、单字下划线一律不用；一个面孔、一个颜色，文字本身负强调。
- **一页最多两种字体，通常一种；字号最多五种，干活的只有三种**【数据】（特大、常规、注脚）。
- **特大与常规字号比拉开**【数据】：目标 2.5 以上；保守的小字号比是弱者特征。
- **等宽字体只给真实代码**【品味】：数字对齐用表格数字，不用等宽。

## 4. 字、空、色、图四律

- **字**：特大字 tracking -0.02 至 -0.05em、行高 0.85–1.05；正文 16–20pt、行高 1.45–1.6、
  每行 45–75 字；默认左对齐，全 deck 最多居中一次。
- **空**：一套网格、一对等宽外边距，全 deck 通用；大元素顶到边缘；正文块全 deck 共用
  2–3 条左边缘。不对称在网格内，不在画框上：半边空必须由对侧的东西（图、第二列、
  数据、列表）封住。页间空隙明显大于页内空隙；每页版式与邻页不同；一页只许一次有意的留白。
- **色**：一地、一墨、一强调色；强调色只给动作和至多一处；表面分隔用底色台阶，
  不用线和阴影；整页可换底色，不渐变。
- **图**：一张主图胜过六张小图；主图占首屏一半以上才叫主图。同批图同裁剪比、同处理、
  直角（方向另有规定除外）。没有图胜过占位图、图标、抽象形；为主题画的图胜过占位；
  真实世界照片（注明来源）胜过画的。任何东西不压在标题和陈述句上。

## 5. 实质重于克制

去装饰只做了一半。另一半是：放大字号、整块底色、真实图片、写满内容。
删了眉标细线卡片却什么都没补的页，叫空，不叫干净。不要用克制换实质。

## 6. 工作流（deck 版）

清单 → 论点 → 选风格（写理由）→ idea 句（过竞争者测试）→ 先写逐字稿
（标题不超两行、内容写满、不编造证据）→ 按 token 建（颜色与字体角色只引用 token）
→ 首屏按蓝图做准 → 每页不同版式 → 门禁自测（标题行数、字号、边距、空白段、压字）
→ 看渲染图、改最严重的三个问题、最多三轮。

## 7. 工作示例：six-styles 演示改成 taste 三页

- 眉标去掉：六套演示每页顶上的"精美 PPT · 六套风格演示"小字全部删除。
- 标题 28pt → 44pt（封面 54pt），特大与常规比从 1.6 拉到 2.4 以上。
- 字号从标题/正文/小字/图注/页码五种收成特大/常规/注脚三种。
- 标题下细线去掉，改留白分隔；表面分隔改底色台阶。
- 柱图双色（藏青首柱 + 青色其余）改单强调色加尺度区分：首柱靠最长表达第一，不靠第二种颜色。
- 主图放大到半屏以上；图注改正常语序 14pt，不用小号字母间距标签。
- 页码 folio 从 10pt 提到 12pt（功能性页码，不是标签）。
- idea 句：3 万多个 skill 的拥挤，变成一眼看清的集中度——拥挤用柱图的长度对比表达，
  不用装饰。
