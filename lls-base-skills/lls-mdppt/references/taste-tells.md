# tells 注册表（PPT 版，日期化）

tell = 让一页读起来像"AI 生成"的做法。tell 会过时：今年禁的，明年可能就是风格。
所以每条带立规日期，定期复审。替代品是程序（从牌库抽、从主题推导），不是产品
（不写"用思源黑体代替"这种——每个"用这个代替"清单几个月内就会变成下一波 tell）。

状态：**banned** 生成前必须避开；**warned** 出现需一句话理由，写进交付报告。

## banned（立规 2026-10-31）

| tell | 替代做法 |
|------|---------|
| "谢谢观看"/"THANK YOU"结尾页 | 结论页：三句话带走 |
| 01/02/03、(001)、Step 2 编号标签 | 顺序由位置、字号、文字表达；页码 folio 不算 |
| 渐变标题、渐变背景 | 纯色；照片下压字的中性罩网是唯一例外 |
| 1px 细线分隔、网格线、裁剪标记 | 留白、底色台阶、字号变化 |
| emoji 做图标/项目符号 | 文字，或真实图片 |
| 图标卡片阵、成排相同卡片 | 按版式蓝图做，不用卡片网格凑数 |
| 助手配色：紫/靛、奶油黄＋陶土 | 发牌定配色 |
| 眉标/药丸徽章（标题上方小标签） | 信息放进标题或首句 |
| 灰条假仪表盘、装饰形、渐变色块 | 真实图表，或删掉 |
| 标题花式强调词（斜体/变色/单字下划线） | 一个面孔一个颜色，文字本身负强调 |

## warned（立规 2026-10-31）

| tell | 说明 |
|------|------|
| 目录页 | 内容少时直接删掉；多时用论点句做目录，不用单名词 |
| 小号全大写字母间距标签 | 用正常语序、可读字号 |
| 一页超过 5 种字号 | 收成特大/常规/注脚三种 |
| 全 deck 居中超过 1 次 | 默认左对齐 |

## 复审

每次 skill 迭代时复审一次：过时的 tell 移入"退役"，新发现的 tell 追加并打日期。
