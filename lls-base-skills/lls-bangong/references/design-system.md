# 设计系统（PPT 演示文稿生成）

> 本文件是 PPT 生成的视觉决策知识库，自研整理。生成 PPT 前先按第一节做风格简报，再按第二节选风格配方。

## 一、先写风格简报（生成前的必做动作）

一句话视觉论题：三个形容词 + 一个有益张力。
例："严谨、克制、有条理——张力在于数据密集但留有呼吸"。

写不出论题就先问用户三个问题：给谁看（受众）／要促成什么判断（目的）／在什么场合投出来（场景）。答案决定密度、配色与版式。

**密度按阅读行为选**：

| 密度 | 适用场景 | 手段 |
| --- | --- | --- |
| 低 | 发布会、故事、煽动 | 大字、少字、满版图 |
| 中 | 内部同步、培训、路演 | 标准要点页 |
| 高 | 决策会、研报、述职 | 分组证据 + 对齐列 + 明确结论，**不是缩小字号** |

## 二、垂直节奏（16:9 页带模型）

一页分六条带，用比例不用坐标：

| 带 | 位置（页高） | 内容 |
| --- | --- | --- |
| 页眉带 | 0–6% | 章节标签 / 页码 / LOGO |
| 论点带 | 6–14% | 页标题，一行以内 |
| 分隔带 | 14–18% | 留白，给眼睛一个停顿 |
| 证据场 | 18–90% | 主表格 / 图表 / 要点 / 对比 |
| 结论带 | 88–93% | 本页结论或来源（可选） |
| 页脚安全区 | 93–100% | 页码，保持视觉独立 |

最常见的失败：标题贴着第一行内容、底部整条空白。修法是拉开标题与内容的间距、把证据场向下延展。

## 三、角色化配色（不背色值，背角色）

每套风格只定义六个角色：背景／主文字／次文字／强调／语义（绿黄红）／细线。禁止超出角色的颜色；强调色一页最多用两处。

## 四、三套内置风格（--style 参数）

### formal 正式工作汇报（缺省）

- 论题：严谨、有序、克制。让状态、偏差、决策在会议上一眼可扫。
- 配色：暖白底、近黑主文字、藏蓝强调、语义色只用于状态。
- 版式轮廓：执行摘要 + 进度行 + 偏差表 + 决策行；状态行 + 实际 vs 目标 + 偏差说明。
- 失败信号：标题过大压住内容、行高松而字小、圆角卡片堆成仪表盘感、状态色变成装饰。

### consulting 咨询研报

- 论题：分析性、压缩、冷静。每页一个论点，证据承重。
- 配色：白底、深灰主文字、单强调色（深蓝或绛红）、细线网格。
- 版式轮廓：论点行（完整句）+ 证据网格（两列对比/数据小倍数）+ 来源行。每页一个主要结论，标题写结论不写话题（"华东区增速领跑"而不是"华东区分析"）。
- 失败信号：话题式标题、证据与结论分离在两页、装饰性图标多于数据。

### teaching 教学课件

- 论题：清晰、亲和、节奏感。一页一个知识点，视觉锚点帮助记忆。
- 配色：浅色底、深主文字、暖色强调（橙/青双强调允许）、大号正文。
- 版式轮廓：知识点页（要点 ≤4 条 + 图示位）+ 练习页（问题大字 + 留白）+ 章节分隔页（满版色块）。
- 失败信号：一页塞进课本整节、字号低于 18pt、连续 5 页同版式无变化。

## 五、要点页规则

- 一页要点 ≤6 条，超出主动拆页或转两列证据网格。
- 每条要点 ≤2 行；需要长句就改成"短句加粗 + 冒号 + 说明"。
- 序号、日期、百分比、金额保持数字原生，不要转图片。

## 六、验证纪律（省时省渲染）

1. 生成后只做一次全量渲染。
2. 先看缩略图总览，再细看：封面、信息最密的一页、图表页、结束页、总览中的异常页。
3. 程序化检查（pptx_check.py）先跑：空占位符、超密度页、要点超量。
4. 没有新的视觉变化就不重复渲染。
