# 运营数据与开发者主页

> 来源：官方文档 /docs/operations-data、/docs/developer-profile ｜ 同步日期：2026-10-24

## 运营数据指标（T+1 更新，当日数据次日可查）

| 指标 | 口径 |
| --- | --- |
| 安装量 | 召唤专家/技能、成功连接连接器计 1 次；按实际次数统计不去重 |
| 调用量 | 技能/专家：读取 skill.md / agent.md 计 1 次；连接器：使用其工具计 1 次；不去重 |
| 留存率 | 7 日留存 = T 日与 T+7 日都产生调用的用户数 ÷ T 日产生调用的用户数 |

专家错误率高 → 本地试用复现失败重试现象，定位后针对性优化。**免费资产的留存与调用量是付费版需求验证数据。**

## 开发者主页（设置 → 开发者信息）

展示：头像、昵称、认证标识（企业主体展示企业全称）、简介、联系方式、已发布资产（技能/专家/连接器/Buddy 应用）。

| 项 | 规范 |
| --- | --- |
| 头像 | 必填，512×512px，≤5000KB，JPG/PNG，无违法侵权误导内容 |
| 昵称 | 必填全平台唯一，2–20 字符；修改后主页与资产署名同步更新 |
| 简介 | 必填 20–120 字符，说明专业方向与主要资产，不得夸大虚假 |

**昵称禁用**：纯数字/纯空格/表情；敏感违法内容；冒充官方/平台/客服/管理员；"官方、平台、客服、管理员、admin"字样；非腾讯主体仿冒腾讯系品牌；"认证、VIP、第一、独家、保证"等误导背书；"测试、test、demo、试用"。

**联系方式**：1–5 项，支持官网/邮箱/微信公众号/自定义平台（填平台名+账号）；不得填违法欺诈侵权内容。

## 违规处置

平台可视情况：恢复默认头像、兜底文案替代简介、隐藏联系方式、限制主页展示、要求整改重提、严重违规下架。收到整改提示及时修改重提，通过后恢复展示。
